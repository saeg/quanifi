QAOA on the Quanifi canvas

Ten reusable lanes (one per QAOA processor) plus an N×M matrix (5 builders × 7 engines), built from the same settings as the two downloadable NiFi snapshots.

Download the lanes flow · Download the N×M flow · Setup and processor reference

All processors import stopped. Start downstream components, then use Run Once on each trigger. Local results below exercise the real processors using NiFi API stubs; they are not a screenshot or a claim of live NiFi execution.
