🐳 Quickstart: Launching Apache NiFi with Docker

To follow along and execute any of these interactive tutorials, start the Quanifi NiFi container from your terminal: 

docker compose up -d

Wait ~30–60 seconds for NiFi to become healthy (check with docker compose ps). Then open https://localhost:8443/nifi in your browser (Username: admin, Password: quanifipassword). For custom processor selections and production options, see the Docker Quickstart Guide.

Visual Quantum Software Engineering

Learn how to compose, test, execute, and monitor quantum algorithms using Apache NiFi dataflows — written specifically for software engineers without a physics background.

Why Quantum Computing Needs Flow-Based Pipelines

In conventional quantum software development, researchers and engineers write monolithic Python scripts or Jupyter Notebooks using libraries like Qiskit, Cirq, or Pennylane. While effective for small prototypes, this approach introduces severe friction in software engineering environments:

  • Vendor Lock-in: Quantum algorithms get tightly coupled to one framework's API. Porting from Qiskit to Cirq or Qrisp requires complete circuit rewrites.
  • Zero Observability: You cannot easily see where circuits are queued, inspect intermediate compiled representations, or handle hardware timeouts.
  • Hard-to-Test Oracles: Quantum oracles (functions tested by algorithms) are hardcoded into scripts rather than decoupled as interchangeable components.

Quanifi solves this by marrying Apache NiFi (a battle-tested enterprise dataflow engine) with quantum compilation and execution engines. Quantum circuits, Hamiltonians, and measurement histograms become standard FlowFiles moving through visual, decoupled processor pipelines.

💡 The Software Engineering Analogy: Microservices & Streams

Think of Quanifi like an event-driven microservices architecture or an ETL data pipeline. Rather than calling a monolithic run_algorithm() function, you chain discrete workers: a Trigger fires an event, an Encoder formats the problem, a Quantum Engine constructs and runs the unitary circuit, and a Reporter verifies the output.
