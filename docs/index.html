Apache NiFi • Quantum Computing Open Source Framework v0.2.0

Visual Quantum Software Engineering with Apache NiFi

Quanifi combines enterprise dataflow orchestration with quantum programming frameworks (Qiskit, Cirq, Qrisp, PennyLane, and pyQuil), allowing quantum circuits, oracles, Hamiltonians, and measurements to flow through reusable visual pipelines.

Quanifi documentation

Docker users: only a subset of processors is installed by default. The full catalogue includes processors that are not in the quickstart image. Add the processors you need to docker/processors.txt, then run docker compose up -d --build nifi. You can also select a custom list or all processors through .env. Enable additional processors.

This directory contains documentation for users and framework contributors. Research plans, experiment protocols and generated study reports are maintained in separate repositories.

Beginner Roadmap

If you are new to Quanifi, follow this 4-step pathway:

  1. Module 1: Introduction to Quanifi — Understand the visual quantum software engineering paradigm and FlowFile dataflow model.
  2. Developer Guide or Docker Quickstart — Set up your Python 3.12 environment with uv or launch the pre-packaged NiFi container.
  3. Configuring flows on the NiFi canvas — Import and execute your first quantum flow using interactive "Run Once".
  4. Interactive Tutorials Curriculum — Work through 6 step-by-step quantum algorithm modules (Deutsch-Jozsa, Bernstein-Vazirani, Grover, QAOA, Graph Decomposition).

Quanifi Project

Visual Quantum Software Engineering with Apache NiFi. Composing, testing, executing and verifying quantum algorithms as enterprise dataflows.

Compatible with Qiskit, Cirq, Qrisp, pyQuil, and PennyLane across local simulators and quantum cloud hardware.
