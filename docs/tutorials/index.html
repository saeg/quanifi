Quanifi Interactive Tutorials

Learn how to compose, test, execute, and monitor quantum algorithms using Apache NiFi dataflows — written specifically for software engineers without a physics background.

Curriculum Overview

Each tutorial module breaks down quantum algorithms into intuitive computational concepts, guides you through running the flow on the live NiFi canvas, shows you how to interpret output reports, and finishes with a hands-on exercise.

Module 01

Introduction to Quanifi

Understand the Quanifi architecture, FlowFile wire contracts, how OpenQASM flows between processors, and how to navigate the NiFi canvas.

Start Module 1 →
Module 02

Deutsch-Jozsa Algorithm

Determine whether a black-box boolean function is constant or balanced in a single evaluation (O(1)) using quantum phase kickback.

Start Module 2 →
Module 03

Bernstein-Vazirani Algorithm

Recover an unknown n-bit secret bitmask in exactly 1 query (O(1)) compared to n queries in classical computing.

Start Module 3 →
Module 04

Grover's Search Algorithm

Search an unstructured database of N items in O(√N) queries using oracle phase inversion and amplitude amplification.

Start Module 4 →
Module 05

QAOA Portfolio Optimization

Solve budget-constrained Markowitz mean-variance portfolio selection using the Quantum Approximate Optimization Algorithm and XY mixers.

Start Module 5 →
Module 06

Graph Cut Decomposition

Decompose large, disconnected problem graphs across independent parallel NiFi processor groups to fit NISQ qubit constraints.

Start Module 6 →

Quanifi Project

Visual Quantum Software Engineering with Apache NiFi. Composing, testing, executing and verifying quantum algorithms as enterprise dataflows.

Compatible with Qiskit, Cirq, Qrisp, pyQuil, and PennyLane across local simulators and quantum cloud hardware.
